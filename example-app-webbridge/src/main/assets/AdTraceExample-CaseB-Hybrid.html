Case B — Hybrid

Native events + Web Bridge

Use this file when Android native code already initialized AdTrace (AdTrace.onCreate / SDK init on native side) and may have tracked events. This page only talks to the same running SDK through the bridge. 

What already happened on Android (before this page):
1. Native AdTrace.onCreate(config)   ← SDK INIT (native)
2. Native AdTrace.trackEvent(...)    ← e.g. Case B button
3. AdTraceBridge.registerAndGetInstance(app, webView)

What this page does:
4. AdTrace.trackEvent(event)         ← JS bridge only
   DO NOT call AdTrace.onCreate here (would log "already initialized")
