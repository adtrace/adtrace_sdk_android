Case A — WebBridge only

No native AdTrace events

Use this file when tracking happens only from HTML/JS. Native Android only registers AdTraceBridge — it does not call native init. 

Integration steps in this page:
1. Include adtrace_*.js
2. new AdTraceConfig(appToken, environment)
3. AdTrace.onCreate(config)   ← SDK INIT (required in Case A)
4. AdTrace.trackEvent(event)  ← track from buttons below
